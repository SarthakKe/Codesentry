# CodeSentry 🛡️

AI-powered GitHub repository security scanner.

CodeSentry analyzes source code repositories for common security risks such as exposed secrets, hardcoded credentials, and potentially dangerous coding patterns.

## Features

- GitHub repository scanning
- Secret and credential detection
- Security vulnerability detection
- Severity classification
- Security score
- AI-powered vulnerability explanations
- Remediation recommendations
- Developer-friendly security dashboard

## Tech Stack

- Python
- FastAPI
- React
- TypeScript
- GitHub REST API
- SQLite
- AI/LLM API
- GitHub Actions



## Project Status

🚧 Currently under development.

### Development Workflow

CodeSentry is developed using a feature-branch workflow with GitHub Pull Requests, code reviews, automated testing, and CI/CD.
